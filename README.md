## Note
These assets were extracted/rebuilt from the supplied branding mockup. The SVG files preserve the approved visual appearance by embedding the transparent raster artwork; they are not manually redrawn path-vector masters. For large-format fabrication, embroidery, or CNC work, a true path-vector redraw is recommended.
